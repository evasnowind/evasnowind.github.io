使用regexp正则匹配纯数字

例如：
当 SELECT “666” REGEXP ‘[^0-9.]’ 结果为 0 ,代表为纯数字
当 SELECT “6hhhhh” REGEXP ‘[^0-9.]’ 时, 结果为1 ,代表不为纯数字
