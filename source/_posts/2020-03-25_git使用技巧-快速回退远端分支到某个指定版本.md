---

先使用下面的命令：

```
git log
```

获取想要回退版本的 commit id，假设这里是 `82d9cab12731870bd04327464e501479da3a87e2`。

然后执行：

```
git reset 82d9cab12731870bd04327464e501479da3a87e2
```

将本地版本回滚到指定 commit。

<!-- more -->

然后执行：

```
git push -f
```

将本地更新强制推送到远端。
