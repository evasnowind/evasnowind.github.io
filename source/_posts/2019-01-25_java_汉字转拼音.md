如果在 Java 项目里有“汉字转拼音”的需求，我更推荐直接使用 `pinyin4j`。它是相对成熟、资料也比较多的一套方案，日常项目里基本够用。

可以参考这篇帖子：[使用 pinyin4j API 将汉字转换为拼音（学习笔记）](https://blog.csdn.net/sky_limitless/article/details/79443540)。

相比之下，Hutool 里的 `PinyinUtil` 目前已经被弃用，也不太推荐继续使用，因为某些汉字可能会转换错误，比如下图中的“馨”：
